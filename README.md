# Monthly Habits — Habit Tracker

Habit tracker visuel en grille circulaire (une couronne par habitude, un rayon par jour).

- À l'ouverture, la to-do list du jour s'affiche : on coche ce qui est fait (+ « ½ » pour le doomscrolling et l'alcool/junk food).
- À minuit, tout ce qui n'a pas été coché passe automatiquement en rouge (pas fait).
- Morning routine : cocher = tout fait ; « détail » pour toucher les étapes non faites (orange si une partie, rouge si rien).
- Observations du jour (onglet « Du jour ») et vue de toutes les observations (onglet « Globales »). Clic sur un numéro de jour dans la grille pour ouvrir ses observations.
- Installable sur iPhone : Safari → Partager → « Sur l’écran d’accueil ».
- La grille se colore en vert, rouge ou orange. Clic sur une case pour la modifier.
- Mode sombre par défaut, bouton emoji en haut à droite pour passer en clair.
- Les données restent dans le navigateur (localStorage). Bouton Exporter/Importer pour les sauvegarder ou les passer sur un autre appareil.
