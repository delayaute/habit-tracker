# Monthly Habits — Habit Tracker

A visual circular habit tracker (one ring per habit, one ray per day).

- On open, today's to-do list pops up: check what you did (+ “½” for half done on 02, 03, 04, 08 and 09).
- Habits 08–10 (no doomscrolling, no alcohol & junk food, no gooning) start checked green every day — uncheck them only if you slipped.
- At midnight, anything else left unchecked automatically turns red.
- Morning routine: checking it = everything done; “details” to tap the steps you did NOT do (orange if some, red if all).
- Daily notes (“Daily” tab) and all notes in one list (“All notes”). Click a day number on the grid to open its note.
- Dark mode by default, emoji button top-right for light mode.
- Optional ☁️ SYNC: saves everything as `habits.json` in a **private** GitHub repo (fine-grained token, Contents read & write) so phone, computer and the widget share the same data.
- iPhone: Safari → Share → “Add to Home Screen” to install it like an app.
- iPhone widget: `widget/habits-widget.js` for the free Scriptable app (reads the same private repo).
